💳 Landing Page — bKash / Nagad / Rocket / Bank

🔔 অর্ডার নোটিফিকেশন (Telegram)

অনলাইন পেমেন্টের (bKash/Nagad/Rocket/Bank) অর্ডার সাবমিট হওয়ার সাথে সাথেই — কাস্টমারকে কোথাও না পাঠিয়ে, পেজ থেকে সরাসরি — আপনার Telegram-এ মেসেজ চলে আসবে।

সেটআপ (২ মিনিট):
১. Telegram-এ @BotFather-কে মেসেজ দিন → /newbot লিখে একটা বট বানান → একটা Token পাবেন, সেটা নিচে বসান।
২. আপনার বানানো বটে গিয়ে যেকোনো একটা মেসেজ পাঠান (যেমন "hi"), যাতে বট আপনাকে চিনতে পারে।
৩. Telegram-এ @userinfobot-কে মেসেজ দিয়ে আপনার Chat ID সংখ্যাটা নিন, সেটাও নিচে বসান।
৪. Save করে "টেস্ট নোটিফিকেশন" বাটনে চেপে যাচাই করুন।
